### 四、财务 Skill 金额量级 Bug 修复（重要）

- 现象：净利润被答成"903,882,531.56 万元"，量级错了 1 万倍。
- 根因：指标定义表 `display_divisor` 字段，金额类（amount）原始值单位是**元**、divisor=10000，需除以 10000 才是**万元**；比率/倍数类 divisor=1。原 `fetch_indicators` 直接返回原始值未换算。
- 修复：`financial_data.py` 的 `fetch_indicators` SELECT 带上 `display_divisor`/`decimal_places`，新增 `_scale_row` 按除数换算并按精度取整，另存 `raw_value` 备查。
- 验证：净利润 → 90,388.25 万元（≈9.04 亿），资产 → 611 万万元（≈611 亿），比率不变。DeepSeek 回答不再自相矛盾。

### 五(补)、财报/财务接口梳理

数据源：GKH 库 5 张表（`cfrm_mock_customer` / `_indicator_definition` / `_indicator_calc_batch` / `_indicator_value` / `_rule_set`）。覆盖 22 个指标，四大类：规模、盈利、偿债、现金流。**不做 NL→SQL，全部固定参数化 SQL。**

#### 1. `POST /skill/financial/ask`（主入口，走 LLM）

- 请求体：`{ "question": "西安正和科技2026年半年报的资产负债率和净利润" }`
- 处理链：DeepSeek 抽参（客户/年份/周期/期次/类别/指标）→ 解析客户 → 定周期（缺则取最新期）→ 取指标 → DeepSeek 合成中文回答
- 成功返回：
  | 字段 | 说明 |
  |---|---|
  | `answer` | LLM 合成的中文回答 |
  | `resolved` | 命中客户（id / customer_code / customer_name …） |
  | `period` | `{year, cycle, period_no}` 实际使用的周期 |
  | `extracted` | LLM 抽取的原始参数（调试用） |
  | `data` | 结构化指标数组（含换算后展示值） |
- 边界返回：未找到客户 → `answer` 提示补充信息，`resolved=null`；多命中 → `answer` 提示确认 + `candidates`；无数据 → 提示暂无数据；异常 → `{answer:"查询出错…", error}` 兜底不 500。

#### 2. `GET /skill/financial/indicators`（免 LLM 直取，前端/联调）

- 查询参数：`customer`（必填，名/编号/ID）、`year`、`cycle`、`period`（后三者可缺，缺则取最新期）
- 返回：`{ ok, resolved, period, data }`；未找到 `ok=false msg`；多命中 `ok=false candidates`
- 示例：`/skill/financial/indicators?customer=西安正和科技&year=2026&cycle=semiannual&period=1`

#### 3. 取数层函数（`financial_data.py`，供上层与后续能力复用）

| 函数 | 作用 |
|---|---|
| `resolve_customer(q)` | 内部ID精确 → 业务编号精确(大小写不敏感) → 客户名 LIKE 模糊；多命中返候选，不瞎猜 |
| `customer_basic(id)` | 客户基础信息 |
| `available_periods(id)` | 可用「年份+周期+期次」列表（`current_marker=1`），最新在前 |
| `latest_period(id)` | 最新可用期（缺周期时默认） |
| `fetch_indicators(id, year, cycle, period, categories?)` | 三表 JOIN 取指标；金额按 `display_divisor` 换算、按 `decimal_places` 取整，另存 `raw_value` |

#### 4. 周期口径（cycle_type / period_no）

| 报告 | cycle_type | period_no | 2021–2025 | 2026 |
|---|---|---|---|---|
| 一季报 | quarterly | 1 | 有 | 有 |
| 半年报 | semiannual | 1 | 有 | 有 |
| 三季报 | quarterly | 3 | 有 | 无 |
| 年报 | annual | 1 | 有 | 无 |

#### 5. 单条指标数据结构（data 数组元素）

`indicator_code` / `indicator_name` / `category_name` / `value_kind`(amount·percent·ratio) / `display_unit`(万元·%·倍) / `indicator_value`(换算后展示值) / `raw_value`(原始值备查) / `value_status`。

#### 6. 覆盖边界

- 覆盖：22 个指标（金额类近似财报科目 + 比率类财务指标）。
- 不覆盖：资产负债表 86 项等**逐条明细科目**不在指标表内，需要时再导入四张财报表（bs/cf/is/oe）并扩展取数层。
